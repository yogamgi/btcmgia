Santri

Kosongkan kolom target untuk memakai target default kategori. Santri nonaktif tidak muncul di form, tapi laporannya tetap dihitung.

Kategori perangkat & target default

Kategori menjadi pilihan "Jenis Perangkat" di form dan kolom Done/Target/Achievement di dashboard.

Pertanyaan form

Kolom "section" mengelompokkan pertanyaan. Pilihan untuk select/radio/checkbox ditulis satu per baris. Pertanyaan tanggal, nama santri, dan jenis perangkat dipakai dashboard sehingga tidak bisa dihapus (label dan urutannya bisa diubah). Jumlah unit tidak ditanyakan: setiap laporan dihitung 1 unit di dashboard. Menghapus pertanyaan tidak menghapus jawaban lama di spreadsheet.

Milestone target kumulatif

Jumlah unit kumulatif yang diharapkan pada hari ke-N. Dipakai untuk status "Sesuai target".
