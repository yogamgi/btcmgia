Santri (semua stage)

Daftar ini dipakai form dan dashboard semua stage. Kolom target hanya untuk Stage 1; kosongkan untuk memakai target default kategori. Santri nonaktif tidak muncul di form, tapi laporannya tetap dihitung.

Pertanyaan form Stage 0

Pilihan Lokasi Cabang dan Aktivitas ditulis satu per baris di kolom "Pilihan". Pertanyaan nama santri tidak bisa dihapus. Menghapus pertanyaan tidak menghapus jawaban lama di spreadsheet.

Pengaturan Stage 1

Judul form, deskripsi, tanggal mulai, buka/tutup form, judul dan pengumuman dashboard. Tambah baris baru untuk catatan sendiri.

Kategori perangkat & target default

Kategori menjadi pilihan "Jenis Perangkat" di form dan kolom Done/Target/Achievement di dashboard.

Pertanyaan form Stage 1

Kolom "section" mengelompokkan pertanyaan. Pilihan untuk select/radio/checkbox ditulis satu per baris. Pertanyaan tanggal, nama santri, dan jenis perangkat dipakai dashboard sehingga tidak bisa dihapus (label dan urutannya bisa diubah). Jumlah unit tidak ditanyakan: setiap laporan dihitung 1 unit di dashboard. Menghapus pertanyaan tidak menghapus jawaban lama di spreadsheet.

Milestone target kumulatif

Jumlah unit kumulatif yang diharapkan pada hari ke-N. Dipakai untuk status "Sesuai target".

Form dan dashboard Stage 2 belum dibuat. Selama terkunci, Guest melihat stage ini sebagai "Terkunci"; jika dibuka, Guest melihat "Segera hadir".
